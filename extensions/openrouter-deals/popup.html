How these recommendations work

Capability tiers are editorial family-level estimates, reviewed September 8, 2026—not benchmark scores. Planning requires a higher tier; coding targets routine implementation. Unknown model families are left unrated. New versions inherit their family's estimate.

Within each role, we compare estimated request cost, capability tier, measured speed, your family preferences and active discounts. Each series appears once. The premium choice favors a higher capability tier and must cost more than every everyday pick; it is not a guaranteed universal best.

Nitro sorts eligible providers by output throughput. It does not increase intelligence or necessarily reduce startup latency. Compare the shown provider and price before switching; use latency routing for faster first tokens.

Speed comes from public API metrics, with public provider-table fallback. Missing or ambiguous measurements stay unavailable. All speed figures are rolling medians, not guarantees.
