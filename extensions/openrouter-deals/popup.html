How these recommendations work

Cheaper uses your estimated request cost. Smarter uses OpenRouter benchmark evidence in the public model catalog. Faster uses OpenRouter's relative model ordering by latency and throughput, with provider measurements when available. Selected choices have equal weight here.

Only OpenAI, Anthropic, Z.ai, Xiaomi, Qwen, Google and DeepSeek models in the weekly top 200 qualify. For each recognizable model family, only its two newest versions are compared. Missing evidence stays missing instead of being guessed from a model name or description.

Nitro sorts eligible providers by output throughput. It does not increase intelligence or necessarily reduce startup latency. Compare the shown provider and price before switching; use latency routing for faster first tokens.

Speed ranks compare models, while any displayed latency and throughput values describe the listed provider. Missing or ambiguous provider measurements stay unavailable. Speed is not a guarantee for your own requests.
