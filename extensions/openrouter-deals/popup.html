How these recommendations work

Intelligent mode uses OpenRouter benchmark evidence for coding, planning, agentic execution, value and critical work. Discovery mode uses only weekly usage, request cost, context and measured provider speed. It does not claim to measure intelligence.

Every valid model in the weekly top 200 can qualify. There is no preferred provider list or family bonus. Missing evidence stays missing instead of being guessed from a model name or description.

Nitro sorts eligible providers by output throughput. It does not increase intelligence or necessarily reduce startup latency. Compare the shown provider and price before switching; use latency routing for faster first tokens.

Speed comes from public API metrics, with public provider-table fallback. Missing or ambiguous measurements stay unavailable. All speed figures are rolling medians, not guarantees.
